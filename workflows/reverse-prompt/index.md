# 参考视频逆向工作流
# Reverse Prompt Workflow

Antigravity 逆向出提示词 → 改核 → 生成。

**状态：制作中。** ComfyUI 版工作流 JSON 尚未跑通。

## 方法（已定）

1. 用 Antigravity CLI 把参考视频反成提示词：运镜、机位、镜头切换、节奏、结构。
2. 先逆向把核找出来，再改核，改成你自己的。
3. 单镜头不超过 15 秒，写动作别写形容词。
